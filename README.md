# POLYGLOT-CODE-PUZZLE-CHALLENGE

A web-based interactive puzzle game testing programming knowledge across 3 different languages: **Python**, **JavaScript**, and **C++**.

## 🎮 Features
- **Level 1 (Python):** Tests knowledge of reference types and mutability.
- **Level 2 (JavaScript):** Tests understanding of dynamic type coercion.
- **Level 3 (C++):** Tests syntax basics and missing elements.

## 🛠 Tech Stack
- HTML5
- CSS3
- JavaScript

## 🚀 How to Run Locally
1. Download or clone this repository.
2. Open `index.html` in any web browser.
